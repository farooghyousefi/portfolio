- Microsoft Associate: [official Microsoft Learn artwork](https://learn.microsoft.com/en-us/media/learn/certification/badges/microsoft-certified-associate-badge.svg). Used for the AZ-104 and AI-103 learning goals; names verified against their Microsoft Learn certification pages.

AWS and Microsoft retain ownership of their artwork. Learning goals are grouped separately and shown in grayscale; they are not included in the site's earned credential metadata. The IHK symbol is a custom qualification illustration, not official badge artwork.
